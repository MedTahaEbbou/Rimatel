# ريماتل (RIMATEL) 🌐🇲🇷
### جيلٌ جديد.. اتصالٌ سديد.. ورقمٌ فريد (7)

بوابة الويب التفاعلية ثلاثية الأبعاد والموقع الرسمي لشركة **ريماتل (RIMATEL)**، المشغل الرائد لخدمات الاتصالات والألياف البصرية وحلول الجيل الخامس (5G) في موريتانيا.

---

## ✨ المميزات الرئيسية (Key Features)

- **تجربة تفاعلية سينمائية (Cinematic 3D Scroll Canvas)**:
  - تدرج لوني ثلاثي الأبعاد مدفوع بالتمرير عبر 70 إطاراً فائق الدقة (`ezgif-frame-001` إلى `070`).
  - تحسين الأداء عبر التحميل المسبق التدريجي وتزامن بمعدل 60 إطاراً في الثانية ودعم كامل لشاشات Retina و DPR.
  - نصوص مسجوعة ومزامنة لحظياً مع تقدم التمرير وحركات المشاهد.

- **دعم كامل لثلاث لغات (Multilingual Architecture)**:
  - 🇸🇦 **العربية (RTL)**: صياغة مسجوعة وبليغة مع خطوط عربية حديثة (Alexandria & Cairo).
  - 🇬🇧 **English (LTR)**: International technical editorial copy.
  - 🇫🇷 **Français (LTR)**: Présentation élégante et moderne des offres télécoms.

- **خدمات ريماتل الأساسية (Core Services)**:
  - 📶 **خطوط الجيل الخامس 5G (رقم 7)**: الهوية البصرية الجديدة ورمزية الرقم 7 للكمال والاستمرارية.
  - ⚡ **فايبر أوبتيك (FTTH)**: إنترنت فائق السرعة عبر الألياف البصرية للمنازل والشركات.
  - 📡 **باقة ساوي (SAWI)**: إنترنت لاسلكي منزلي مفتوح بدون حدود عبر أجهزة الواي فاي.
  - 💳 **تطبيق السداد والدفع الرقمي**: تجديد فوري للاشتراكات مع خصومات حصرية.

- **تصميم فخم ومتجاوب بالكامل (Glassmorphic Mobile-First Design)**:
  - زجاج مثلج حديث (`Glassmorphism`)، وتباين نيون زمردي وليموني مستوحى من هوية الشركة.
  - تثبيت ذكي وسلس (`position: sticky` مع وحدات `100dvh`) على كافة شاشات الهواتف والأجهزة اللوحية والحواسيب.

---

## 🚀 التقنيات المستخدمة (Tech Stack)

- **HTML5**: بنية دلالية محسنة لمحركات البحث (SEO).
- **CSS3 (Vanilla)**: تصميم متجاوب بدون مكتبات خارجية، يدعم وحدات `dvh` و `clip` و `Glassmorphism`.
- **JavaScript (ES6+)**: محرك تحريك وتفاعل الكانفاس، ومصفوفة اللغات المتزامنة، والتحميل التفاعلي.

## 💻 التشغيل المحلي (Local Preview)

يمكن فتح `index.html` مباشرة في أي متصفح، أو تشغيل خادم محلي خفيف:

```bash
# باستخدام بايثون
python -m http.server 8080

# أو باستخدام Node.js
npx serve
```

ثم التوجه إلى: `http://localhost:8080`
